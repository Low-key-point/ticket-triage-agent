# 评估范围调整记录

日期：2026年11月6日。

项目负责人确认不开展访谈、真实用户实验或人工耗时实验，评估由可复现的自动化实验完成。课程原文件未强制上述用户研究，要求可信测试、定量指标、对照及错误分析，本项目按这些要求交付。

1. 不宣称具有访谈证据；需求价值依据公开客服意图任务及可观察的分流流程。
2. 撤销需求分析中的访谈计划和人工中位耗时下降20%目标，不将程序耗时当作人工节省时间。
3. 保留人工复核界面；使用自动化操作验证确认、修正和状态变化，模拟复核不得冒充真实客服决定。
4. 120条边界样例明确标记为 AI 辅助构造，按预期行为检查，不能视为真实业务分布。
5. 60条端到端任务分别报告自动解决、等待复核和测试驱动器按真值完成复核后的状态，禁止将全部送审算为自动成功。
6. 数据划分、宏平均 F1、自动分流正确率与覆盖率等已冻结目标不变；未达标时如实分析。

本记录是需求分析的有效补充。最终报告仅陈述实际完成的实验和观察。
