# 银行客服工单分流智能体需求分析

## 1 项目定位

本项目面向银行客服咨询的初步识别与流转。目标用户是课程模拟场景中的客服接待人员与复核人员；用户提交咨询后，系统识别业务类别、查询对应演示说明，并创建可追溯工单。机器学习用于判断咨询意图，Agent负责按状态调用工具、选择自动流转或人工复核、处理失败及保存结果。

需求依据公开银行意图任务与可观察的客服处理流程，不宣称已访谈银行员工或测量真实人工收益。项目由单人完成。应用场景使用中文咨询；本轮接入 DeepSeek，先交付运行版与测试说明，验收通过后再更新报告。

## 2 问题与目标

用户常用口语表达“我账户还有多少钱”“卡刷不了”“手机上的银行软件打不开”。不同措辞可能指向同一业务，而敏感、含糊或同时提出多个诉求的请求不宜直接分流。

系统需要完成输入校验、脱敏、14类意图预测、候选说明、知识查询、创建工单、必要时人工确认与最终状态记录。成功标准是业务建议正确且流程可运行、可核验；不以“每条都自动结束”为成功。

## 3 业务范围

支持境外用卡、修改地址、应用故障、取款限额、查询余额、企业贷款、银行卡故障、现金存款、自动扣款、冻结账户、大额支付、联名账户、查询近期交易、账单支付。

每类映射到演示队列。映射是课程设计，不冒充真实银行组织。企业贷款、冻结账户、大额支付进入人工专席；系统不进行授信判断、账户冻结、资金转移或代付。投资、卡片配送、汇率等非本版类别需复核。

“其他”为人工归档专用类别：仅待复核工单可由复核人员选择并填写理由，归入其他工单队列。自动预测、合成增强与候选训练仍限定为14类；系统不能自动将范围外工单直接归档到“其他”。

## 4 功能需求

| 编号 | 功能 | 验收行为 |
| --- | --- | --- |
| FR01 | 输入校验 | 接收2至500字符，异常结构或长度明确报错 |
| FR02 | 14类预测 | 返回前三候选、概率估计和模型版本 |
| FR03 | 决策说明 | 展示对本次分类有正贡献的字符特征，说明其不是业务事实 |
| FR04 | 策略与复核 | 低置信度、敏感、多诉求、范围外或不支持语言转复核 |
| FR05 | 业务知识查询 | 返回版本化演示说明，缺失或错误时明确转人工 |
| FR06 | 工单持久化 | 保存脱敏文本、原建议、最终决定和状态轨迹 |
| FR07 | 幂等与冲突 | 同编号同内容返回既有记录；不同内容拒绝覆盖 |
| FR08 | 人工修正 | 只在复核工作台确认最终类别及理由，处理工单页仅展示结果与跳转入口；结束后不得重复确认 |
| FR09 | 批量输入输出 | 支持UTF-8 CSV，逐行报错并转义表格公式字符 |
| FR10 | 工单工作台 | 提交、候选、说明、轨迹、复核列表、结果统计 |
| FR11 | 实验可核验 | 展示基础模型实际指标与限制，候选验证结果独立标注 |
| FR12 | 大模型配置 | 页面填写密钥、清除配置、真实连接测试；明确网络和额度消耗 |
| FR13 | 复核摘要 | 输出核心诉求、原文依据、待补充信息和复核建议；错误回退，不改分类和人工决定 |
| FR14 | 模拟与增强 | 按14类生成，保留来源、模型、提示版本、种子编号和调用量；边界模拟不参加训练 |
| FR15 | 数据审核与隔离 | 原始四划分冻结，仅训练示例进提示；重复和疑似隐私隔离，待审样本不能训练 |
| FR17 | 其他人工归档 | 人工复核可选“其他”，保留理由和原建议，工作台可筛选、导出最终类别；自动路径禁止归档 |
| FR16 | 候选实验 | 已审核增强样本与原训练集拟合，原校准集校准、原验证集比较，不自动替换基础模型 |

## 5 数据需求

采用公开MInDS-14中文子集，固定源版本、校验文件哈希。只使用中文转写及原始意图标签，不读取英文转写或语音特征。原语料包含口语和语音识别噪声，不能据数据集名称假定所有转写都是中文。

数据准备检查文本、标签和规模，移除无汉字转写及规范化后的精确重复。使用不从语料学习词表的哈希字符表示检测高相似文本，将相似组放入同一划分，减少模板泄漏。训练、校准、验证、测试分别承担拟合、概率校准、策略选择和最终评价职责，测试不用于调参。

数据来源的中文子集不等同于国内银行的真实生产客户记录；必须保留这一来源边界。公开数据许可、版本、清洗变更均记录并随报告交付。

生成数据单独标注为大模型合成，存放在本机。训练增强与模拟演示分开，逐条人工审核后才能加入候选实验。增强效果以验证集比较为准，不预设提升。数据候选核查见《数据集候选核查》。

## 6 非功能需求

本地分类与候选训练使用本机CPU。DeepSeek用于复核摘要、模拟工单与训练增强，用户在页面填写API密钥；只有显式发起大模型功能或开启自动摘要时才调用外部接口，发送脱敏文本。密钥仅保存在服务端内存，8小时过期或服务重启后清除，不写磁盘或回显。存储和知识调用有限重试，不因故障无限循环。SQL采用参数化查询，页面以文本节点渲染输入，限制本机来源，导出时处理公式注入。

脱敏是启发式，不能保证去除全部个人信息。演示使用公开或虚构文本，禁止提交真实口令与账户凭证。模型仅加载可信本地训练产物，生产部署需另行鉴权与安全设计。

## 7 评估与验收

沿用性能目标：宏平均F1至少0.80，自动分流队列正确率至少0.95且覆盖率至少0.50。报告准确率、各类指标、混淆矩阵、校准误差、置信区间和实际错分数；小样本下即使点估计达标，也不解释为生产保证。

基线包含多数类、关键词、朴素贝叶斯、逻辑回归和未校准模型；比较去掉概率门槛与全部直接分流。模型选择只在训练部分三折分组交叉验证。概率阈值只在验证部分选择。

另有60条AI辅助构造边界，覆盖范围外、不支持语言、多诉求、敏感内容、无效输入和工具故障。流程检查区分自动结束、待复核与按真值脚本复核，不将脚本扮演真人。记录100次核心处理与100次进程内HTTP耗时，不推算人工时间收益。

新增功能按《测试使用说明》验收。未取得用户密钥时，只能完成接口替身测试和本地流程验证，不能宣称完成真实DeepSeek联调。

## 8 交付与限制

交付公开代码、Markdown步骤、可运行页面、依赖锁、数据和训练脚本、实验原始证据、课程报告、演示指南与许可证说明。含身份信息的正式报告、学号姓名、模型和原始实验文件仅在本地提交包保留；不含身份信息的基线报告正文可在仓库阅读。

重点风险包括样本少、重复口语模板、识别噪声、未知业务和概率失准；通过分组隔离、保留失败、复核入口和限制声明应对。未来扩展需要新的独立中文数据，不反复使用已看过的测试集调参。
