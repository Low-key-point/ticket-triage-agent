# 数据集候选核查

核查日期：2026-11-07。目标是寻找适合银行客服工单分流的补充数据，优先真实客服语料，并核对标签、来源及使用许可。本页是数据调查记录，不是新增实验结果。

## 核查结果

| 数据集 | 来源与内容 | 真实程度及许可 | 本版处理 |
| --- | --- | --- | --- |
| MInDS-14，zh-CN子集 | PolyAI发布的银行意图语音转写，14类；原始502条 | 公开研究语料，CC BY 4.0；不能称为国内银行生产工单 | 保留为基线；固定文件、版本、清洗与四划分 |
| JDDC | 京东团队发布研究：超过100万段多轮电商客服对话，2000万条话语，附意图信息 | 论文明确描述来自真实电商场景；本次未核实完整、当前可用的数据下载路径和数据许可。论文开放许可不等于数据许可 | 业务不是银行，标签不匹配；不下载镜像、不直接混入训练，也不声称已获得可用银行工单 |
| CrossWOZ | 清华团队任务型对话，约6000段、10.2万条话语；酒店、餐馆、景点、地铁、出租车 | 人工采集的角色扮演对话，非银行生产工单；仓库LICENSE为Apache 2.0 | 可研究对话状态和模拟机制；现有14类银行任务不采用 |
| RiSAWOZ | 约1.12万段人工多轮对话、超过15万条话语，覆盖12个领域，含语义标注 | 人与人角色扮演采集，非银行生产工单；README数据许可明确为CC BY-NC 4.0。仓库代码许可与数据许可需区分 | 可作对话研究的非商业候选；不直接合并银行意图标签 |
| BBT-FinCUGE / CFLEB相关数据 | 金融新闻摘要、问答、新闻分类、关系抽取、情感等任务 | 公开金融研究项目；各子集来源与许可仍需分别核对，不能概括为真实银行客服数据 | 金融领域相关，但文本与标签不匹配；本版不采用 |

**结论：找到了论文明确描述的真实客服数据JDDC，但本次没有找到来源、许可、标签都已核实且能直接加入当前14类银行分流任务的补充数据。** 这不代表相关数据不存在，只说明本次核查不足以支持合并训练。继续使用现有基线与单独标注的大模型合成增强候选。

## 合成增强如何使用

1. 原训练240、校准61、验证74、测试95条保持冻结。
2. 仅从原训练集按类别选取最多3条示例发送给DeepSeek；验证、测试和校准文本不进入提示。
3. 返回样本标注为“大模型合成”，记录模型、生成时间、提示版本、种子编号、提示内容哈希和供应商返回的Token用量。
4. 本机检查长度、疑似号码或邮箱、精确重复与近重复；对原四划分和已生成样本进行重复隔离。相似检查只使用文本，不使用保留集标签来训练模型。
5. 通过检查的样本仍为待审核。人工确认语义和类别后，才能加入候选训练；生成器自己写的标签不当作独立标注证据。
6. 多诉求、范围外、信息不足等模拟只用于演示，不参加训练。它们不能自动归入“其他”；“其他”只由工单人工复核选择。
7. 原训练加审核样本生成单独候选模型，使用原校准集和原验证集比较；不覆盖基础模型，不拿原测试集反复选型。

生成数据无法代替独立真实样本，也不能保证扩展后的泛化能力。没有实际生成及对照结果前，不宣称增强有效。
